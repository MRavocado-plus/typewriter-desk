
# Typewriter Focus Desk

A distraction-free Pomodoro focus timer and session task list built with pure HTML, CSS, and JavaScript (zero images).

## How to Run
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Or visit the live GitHub Pages link directly.

## Keyboard Shortcuts
- **S**: Start or Pause the timer
- **R**: Reset the timer
- **N**: Focus the New Task input
- **T**: Cycle through themes (Paper, Sepia, Night)
- **M**: Switch between Focus (25m) and Break (5m) modes
